::: note How gating behaves
A feature your plan does not include renders visibly disabled with the plan named. It is never a live control that reveals a paywall when you press it. Server-side saves and the storefront both enforce the plan independently, so a downgrade takes effect everywhere with nothing to clean up.
:::
